PoseHarvest-and-Replay prototype

Drop or choose a CSV or JSON file containing per-frame pose/orientation time-series. The page validates and normalizes records into a common schema: {t: milliseconds, x,y,z, qx,qy,qz,qw}. Use the replay controls to play, pause, and scrub. No dependencies.

Notes: This is a small client-side prototype focused on format normalization and inspection. Crawling and repository harvesting are not implemented here.
